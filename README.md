# The Funniest Honest Appliance Error

**Chosen line:** `Descale overdue. Water hardness: your problem.`

**Why it's funny:** It bluntly shifts blame to the user's water supply instead of the machine, like a passive-aggressive roommate.

**How to run:** `python3 main.py` — writes `entry.txt`.
